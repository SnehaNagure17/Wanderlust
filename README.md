# Wanderlust 🏡

Wanderlust is a full-stack accommodation listing web application where users can explore places, create and manage listings, add reviews, and view property locations on a map.

I built this project to get hands-on experience with building a complete web application and to understand how the frontend, backend, database, authentication, and external services work together.

## ✨ Features

* User signup and login
* Create, edit, and delete listings
* Upload listing images
* Search listings by country
* View detailed listing information
* Add and delete reviews
* Interactive maps for listing locations
* Authentication and authorization
* Form and server-side validation
* Flash messages for user feedback
* Responsive design

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, Bootstrap, EJS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose
* **Authentication:** Passport.js
* **Image Storage:** Cloudinary
* **Maps:** Mapbox

## 📈 Project Impact

Built Wanderlust to gain practical experience in full-stack development. While working on this project, I learned how to handle authentication, CRUD operations, database relationships, image uploads, reviews, maps, and API integration.

## 🚀 Installation

1. Clone the repository:

```bash
git clone https://github.com/SnehaNagure17/Wanderlust.git
```

2. Go to the project folder:

```bash
cd Wanderlust
```

3. Install dependencies:

```bash
npm install
```

4. Create a `.env` file and add your required environment variables:

```env
ATLASDB_URL=your_mongodb_connection_string
CLOUDINARY_CLOUD_NAME=your_cloudinary_name
CLOUDINARY_KEY=your_cloudinary_key
CLOUDINARY_SECRET=your_cloudinary_secret
MAP_TOKEN=your_mapbox_token
SECRET=your_session_secret
```

5. Start the application:

```bash
node app.js
```

6. Open the application in your browser:

```text
http://localhost:8080/listings
```
